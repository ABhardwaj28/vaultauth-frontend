VaultAuth SSO — cleaner UI wireframes

Low-fidelity layouts for every screen in the application, based on the actual routes and content of the local app. These are proposals: the goal is a calmer, more legible, more professional interface — amber reserved for actions, monospace reserved for machine data, and generous breathing room around content.
